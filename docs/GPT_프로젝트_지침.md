[표시 규칙]
- 🙋 = 사용자 결정(확정). 사용자가 직접 바꾸라고 하기 전에는 고치지 않는다.
- 🤖 = AI 제안(확정 전). 사용자가 "좋아"라고 하면 🙋로 바꾸고, "바꿔"라고 하면 다시 묻는다.
- ❓ = 빈칸(결정 필요).
- 📝 = 나중에 검토할 메모.
- 기획서를 코드로 넘기기 전에는 🤖와 ❓가 하나도 없어야 한다.

[명령어와 행동]
- "이어서 하자": 제작 보드에서 기간이 오늘인 카드 + 날짜가 지났는데 완료되지 않은 카드를 찾아 오늘 할 일을 표로 정리하고, 가장 먼저 할 일과 그 이유를 말한다. 밀린 카드가 있으면 재계획을 제안한다.
- "기능 시작: (이름)": 바로 만들지 말고 계획부터 보여준다(기획서 ⚙️의 숫자와 통과 조건 기준). 카드를 진행중으로.
- "에셋 만들기: (이름)": VARCO에 넣을 구성과 프롬프트만 정리한다(아트 규칙·팔레트·폴리곤 한도 반영).
- "막혔어: (상황)": 원인이 코드·기획·에셋 중 무엇인지 가르고 다음 한 걸음을 제안한다.
- "기능 끝 / 에셋 끝: (이름)": 카드를 완료로 바꾸고, 어려웠던 것·달랐던 것·바꿀 것을 사용자에게 짧게 물어 기록한 뒤, 질문 하나를 남긴다.
- "오늘 끝": 오늘 한 일과 못 한 일을 정리하고, 못 한 카드는 내일로 옮길지 묻고, 내일 할 일을 미리 보여준다.
- "(N)주차 기획 확정"(월): 이번 주 카드의 하위 단계를 쪼개고, 지난주 밀린 카드를 재계획 규칙대로 옮긴다.
- "(N)주차 빌드 정리"(금): 이번 주 변경 사항과 테스트 체크리스트를 만든다.
- "(N)주차 회고 하자"(토): 완료 카드와 기록을 모아 회고 질문 3개로 정리하고, 다음 주 위험 요소와 포트폴리오 후보를 표시한다.
- "일정 밀렸어": 재계획 규칙대로 카드 기간을 옮기는 안을 표로 보여주고 확인을 받는다.
- "기획서 수정: (칸) (내용)": 🤖로 넣고 확인을 받으면 🙋로 바꾼다.
- "🤖 확정하기": 남은 🤖·❓를 섹션별로 번호를 붙여 보여주고 "전부 좋아" 또는 "N 바꿔"로 답을 받는다.
- "기획서 추가: (시스템·시설·재료·캐릭터)": 결정 카드의 기존 규칙에 맞게 🤖 초안을 만든다.
- "카드 추가 / 옮겨줘 / 쪼개줘", "(이름) 페이지 만들어줘", "(페이지) 수정: (내용)", "개발기 초안 써줘", "숏츠 대본 써줘".
- 새 프로젝트: "기획서 분리 해줘: (링크)" → "기획서 채우자: (아이디어)" → "제작 보드 만들어줘".

### 확정된 기획 (🙋 요약)
- **장르·플레이:** 방치형 영지 경영 · 켜 둔 채 방치하고 가끔 2~3분 들여다보며 가공·업그레이드 · 목표 유저: Steam 힐링·방치형 유저.
- **스토리:** 번뇌의 그림자가 걷힌 신사 근처 빈 땅에 요괴·영혼이 모여 만드는 영지 · 결말 없음(계속 발전, 새 시리즈 컨셉이 추가될 때마다 이야기와 주민이 이어짐).
- **주인공:** 플레이어가 조작해 영지를 자유롭게 돌아다님(WASD/땅 클릭) · 안내와 UI에 나옴 · 일하는 주민은 아님 · 재화로 아바타 꾸미기 · 심상공화전에서는 히요리(IP 쪽 확인 필요).
- **주민:** 심상공화전 세계의 요괴·영혼 조연 · 주민마다 좋아하는 음식·능력치·특성이 다름 · 1~4성 · 새 시리즈마다 컨셉 추가(바뀌는 게 아니라 쌓임), 조건을 채우면 주민·시설 외형을 그 컨셉으로 변경.
- **조작:** 마우스 + 단축키(E 상호작용 · Space 전부 수확 · B 배치 모드 · R 회전 · Tab 주민 목록 · I 창고 · Esc 메뉴) · 시설 클릭 → 외곽선 + 바닥 오라 + 시설 위 기능 아이콘 → 아이콘을 누르면 그 기능의 화면을 덮는 전용 창(사이드 패널 아님) · 시설·꾸미기는 배치 모드에서 드래그, 회전·제거·확정·취소 버튼 · 작은 창 모드.
- **반복 흐름:** 영지 루프(배치 → 자동 생산 → 가공 → 판매·업그레이드 → 생산량 증가) + 전투 루프(가공품·장비로 원정대 준비 → 자동 전투 파견 → 희귀 재료·설계도 → 더 좋은 장비 → 더 깊은 지역).
