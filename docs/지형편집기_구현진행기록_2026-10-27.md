# 지형 편집기 보완 시도 · 2026-10-27

## 출발점과 결정 주체

- 사용자: 전체 지형의 구조를 읽기 어렵고 원하는 높이·모양을 만들기 어렵다고 설명했다. 특정 맵에 종속되지 않는, 기능이 잘 보이는 편집 창과 실제 구현·노션 기록을 요청했다.
- Codex: 평지·산·연결 길의 수치를 설계 데이터로 저장하고, 지도와 3D 미리보기에서 확인한 뒤 Landscape에 적용하는 제작용 플러그인 첫 버전을 제안·구현했다. 세부 수치·UI 배치는 AI 제안이며 최종 사용자 승인으로 기록하지 않는다.
- 기존 공통 표면·런타임 페인팅 검증이 완료됐다는 사실과 새 제작 편집기의 구현 완료는 별개다.

## 노션 기록

[3주차 기능 4: 지형 확장 1: 공통 표면·언덕 검증 맵](https://app.notion.com/p/3fd10d86fdd581518a81c415799a3d09)에 후속 보완 절을 추가했다. 문제·기존 방식·시도하는 방법·예상 장단점·검증 기준과 구성안 이미지 두 장이 들어갔다. 원래 완료 기록과 상태는 유지했다. 이미지가 카드 본문에 첨부된 것도 읽기로 확인했다.

## 구현 범위와 사용 방식

`CozyRealm/Plugins/CozyTerrainEditor`의 에디터 전용 모듈이다. 실행 게임용 지형 편집기가 아니다. 목표 진입점은 언리얼의 **창 → 지형 편집기**, 또는 콘솔 `Cozy.TerrainEditor`다.

1. 새 설계 또는 선택한 기존 Landscape 연결.
2. 지도에서 평지·산 추가, 위치·가로·세로·높이·연결 폭 수정.
3. 경유점으로 지형 연결 길 설계. 높이 색·5m 등고선·급경사 표시와 3D 미리보기.
4. 설정 저장·불러오기로 다른 맵에서 재사용.
5. 실제 Landscape에는 높이 차이를 전용 편집 레이어로 적용하고 적용 전 레이어 사본을 로컬에 저장. 원래 레이어를 삭제하지 않는다.

처음 기본 지형을 만드는 데는 Landscape 브러시를 직접 다루지 않는 흐름을 목표로 한다. 세밀한 자연 형태, 수직 절벽·동굴·다리, 최종 아트와 소품 배치는 별도 작업이다. 구성안의 숲·건물·강 자동 생성이나 자유형 윤곽 편집까지 구현했다고 주장하지 않는다.

## 현재 진행 상태

- 소스 작성: 평지·산·길 높이 계산, 지도 UI, 3D 미리보기, Landscape 연결·적용·복구, JSON 재사용 설정.
- 편집기 모듈 빌드 성공. 실제 Landscape와 수식·재사용 자동 검사 2개가 통과했다. 예제의 게임 실행·시점 조작 녹화와 프레임 검수까지 확인했다. 기존 게임 전체 통합 검증과 구분한다.
- 현재 체크아웃 `feat/first-run-guide`. 기존 산 월드 작업 브랜치로 전환하지 않았다. 기존 `.uproject`, 테마 에셋, AGENTS.md 등 사용자 변경은 유지한다.

## 예상 장단점 · 검증 전

장점: 동일한 수치 기준, 반복 수정과 설정 재사용, 전체 구조 확인, 원본 레이어 분리. 실제 제작 시간 단축은 아직 측정하지 않았다.

제약: 타원형 평지와 완만한 산 중심의 첫 버전, Landscape 높이장 특성, 최종 아트 자동 완성 불가. 기존 연결은 로드된 일반 Landscape·회전 0·양수 배율·최대 약 100만 높이점 범위에서 우선 검증한다. 대규모 분할 월드 전체 지원은 미확인이다.
