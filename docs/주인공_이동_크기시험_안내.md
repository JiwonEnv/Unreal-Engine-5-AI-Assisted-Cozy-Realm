# 주인공 이동 · 크기 시험 안내

2026-10-18 · 4주차 기능 1 (3D 주인공 이동 · 앞당겨 시작) + 크기 기준 정하기 카드 · 결정: 사용자 · 구현: Claude

주인공은 3D 에셋(5주차)이 나오기 전까지 **기본 도형**(원기둥 몸통 + 구 머리 + 앞쪽 표시 상자)으로 둔다.
키·비율·속도를 플레이 중에 바꿔 보며 건물과의 크기 비율을 정하는 데 쓴다.

---

## 1. 조작

| 입력 | 하는 일 |
|---|---|
| **W A S D** | 이동 (카메라가 바라보는 방향 기준 · W = 화면 위쪽) |
| **Shift** + WASD | 달리기 (설정에서 0이면 없음) |
| **오른쪽 클릭 · 땅** | 그 자리로 걸어감 (칸 격자로 길을 찾아 시설을 돌아감) |
| **오른쪽 클릭 · 시설** | 이동하지 않고 그 시설 기능 메뉴 (🙋 사용자 결정) |
| **E** | 상호작용 거리 안의 가장 가까운 시설 메뉴 · 없으면 안내 |
| 조작 없음 | 정해진 시간이 지나면 스스로 산책 (조금 걷고 쉬고를 반복) · 키나 마우스 버튼을 누르면 멈춤 |

- 창이 열려 있거나 배치 모드(B)일 때는 움직이지 않는다. 배치 중에는 산책도 멈춘다.
- 시설을 옮겨서 주인공 자리를 덮으면 가장 가까운 빈 칸으로 옮겨 간다.
- 작은 창 모드에서는 WASD와 산책만 된다(오른쪽 클릭·E는 크게 보기 후).
- 영지(12×12칸) 밖으로는 나가지 않는다.
- 카메라는 항상 주인공을 부드럽게 따라간다 (🙋 사용자 결정).

## 2. 숫자 고치는 곳 — `Content/CozyRealm/Data/Hero/DA_HeroSettings`

플레이 중에 바꿔도 바로 반영된다. 길이는 cm, 거리·속도는 **칸**(1칸 = 200cm).

| 칸 | 지금 값 | 뜻 |
|---|---|---|
| Height (키 cm) | 120 | 주인공 키 · 후보 90 · 120 · 160 |
| Head Ratio (머리 비율) | 0.4 | 머리 지름 ÷ 키 (SD 비율) |
| Body Width Ratio (몸통 굵기) | 0.75 | 몸통 지름 ÷ 머리 지름 |
| Compare Heights (비교용 인형 키) | 90, 160 | 주인공 시작 자리 옆에 서는 회색 인형 · 머리 위에 키 숫자 · 비우면 없음 |
| Walk Speed (걷기 칸/초) | 1.5 | 초당 3m · 🤖 기획서 초안은 3칸(초당 6m) |
| Run Speed (Shift 달리기 칸/초) | 3 | 0이면 달리기 없음 |
| Interact Range (E 거리 칸) | 1.5 | 시설이 차지한 칸 테두리까지 거리 · 🤖 기획서 초안 |
| Idle Before Wander (산책 시작까지 초) | 10 | 0이면 산책 안 함 · 🤖 기획서 초안 |
| Wander Radius · Pause · Speed Ratio | 4칸 · 2~4초 · 0.6 | 산책 한 번 거리 · 쉬는 시간 · 걷기 대비 속도 |

- 카메라 따라가기 속도: `Data/Camera/DA_CameraSettings_Estate` → **Follow Speed** (지금 4 · 0이면 따라가지 않음)
- 주인공을 끄려면: 프로젝트 설정 → **Cozy Hero (주인공 설정)** → Hero Settings를 비운다 (`Config/DefaultGame.ini` `[/Script/CozyRealm.CozyHeroProjectSettings]`).

## 3. 크기 시험하는 법

1. 에디터에서 플레이(PIE) → 주인공과 비교용 인형(90 · 160cm)이 영지 가운데 근처에 선다.
2. `DA_HeroSettings`를 열어 둔 채 **Height**를 바꿔 보며 시설(신사 320 · 제분소 220 · 나가야 180 · 밭 관리 120cm …) 옆으로 걸어가 비교한다.
3. 마음에 드는 키 · 속도를 정하면 노션 '크기 기준 정하기' 카드에 적는다 → 기획서 5 아트 · 에셋 후가공 체크리스트에 반영.
