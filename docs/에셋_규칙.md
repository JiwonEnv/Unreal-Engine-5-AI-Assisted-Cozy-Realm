# 에셋 규칙 — CozyRealm

언리얼 Content 폴더 구조와 에셋 이름 규칙이다. [Allar UE5 Style Guide](https://github.com/Allar/ue5-style-guide)를 바탕으로 이 프로젝트에 맞게 줄였다.

## 폴더 구조

게임 에셋은 모두 `Content/CozyRealm/` 아래에 둔다. 엔진·템플릿·마켓 에셋과 섞이지 않게 하려는 것이다.
**기능(무엇에 쓰이나)별로 폴더를 나누고**, 그 안에 메시·머티리얼·텍스처·블루프린트를 같이 둔다. 시설 하나를 고칠 때 한 폴더만 열면 되게 하려는 것이다.

```text
Content/CozyRealm/
├─ Core/            게임 모드 · 컨트롤러 등 블루프린트 (C++ 클래스의 자식)
├─ Maps/            레벨 (L_Estate …)
├─ Data/
│  ├─ Camera/       카메라 설정 (DA_CameraSettings_Estate)
│  └─ Tables/       데이터 테이블 · 커브 테이블 (DT_Facility · DT_Recipe · DT_Resident …)
├─ Facilities/      시설별 폴더 (WheatField · Mill …) — SM · M · MI · T · BP 함께
├─ Characters/      캐릭터별 폴더 — SK · ABP · AM · M · T 함께
│  ├─ Player/       주인공 (히요리)
│  ├─ Residents/    주민 (Onibi · 요괴 주민 · 영입 전 방문객도 여기)
│  ├─ Enemies/      번뇌의 그림자
│  └─ Shared/       공용 스켈레톤 · 애니메이션
├─ Environment/     땅 · 풀 · 나무 · 바위 · 물
├─ Decor/           꾸미기 소품 (등롱 · 벚나무 …)
├─ UI/              HUD · 위젯 · 아이콘 · 폰트
├─ Audio/           BGM · 효과음
├─ Shared/          여러 곳에서 쓰는 머티리얼·텍스처·이펙트
└─ Dev/             테스트용 임시 에셋 (출시 빌드에서 제외)
```

- `SourceArt/`(레포 루트)도 같은 이름으로 나눈다: `SourceArt/Facilities/WheatField/` ↔ `Content/CozyRealm/Facilities/WheatField/` · `SourceArt/Characters/Residents/Onibi/` ↔ `Content/CozyRealm/Characters/Residents/Onibi/`
- `Content/TopDown` · `Characters` · `LevelPrototyping` · `Cursor`는 템플릿 에셋이다. 3주차 3D 주인공 작업 때 참고하고, 그 뒤 정리한다.
- `Content/Developers/`는 개인 실험용이다. 여기 에셋을 게임 에셋이 참조하면 안 된다.

## 이름 규칙

`접두사_이름_변형` · 이름은 영어 PascalCase · 한글·공백 금지 · 변형은 `_A` `_B` `_01`

| 접두사 | 에셋 | 예시 |
|---|---|---|
| `L_` | 레벨 | `L_Estate` |
| `BP_` | 블루프린트 | `BP_Facility_WheatField` |
| `WBP_` | 위젯 블루프린트 | `WBP_HUD` · `WBP_FacilityWindow` |
| `DA_` | 데이터 에셋 | `DA_CameraSettings_Estate` |
| `DT_` | 데이터 테이블 | `DT_Facility` · `DT_Recipe` |
| `CT_` | 커브 테이블 | `CT_UpgradeCost` |
| `E_` / `F_` | 블루프린트 열거형 / 구조체 | `E_FacilityType` |
| `SM_` | 스태틱 메시 | `SM_WheatField_A` |
| `SK_` | 스켈레탈 메시 | `SK_Onibi` |
| `ABP_` · `AM_` · `A_` | 애님 블루프린트 · 몽타주 · 애니메이션 시퀀스 | `A_Onibi_Float` |
| `M_` · `MI_` · `MF_` | 머티리얼 · 머티리얼 인스턴스 · 머티리얼 함수 | `MI_WheatField_A` |
| `T_` | 텍스처 (뒤에 용도) | `T_WheatField_A_D` |
| `NS_` | 나이아가라 이펙트 | `NS_HarvestPop` |
| `S_` · `SC_` | 사운드 웨이브 · 사운드 큐 | `S_HarvestDone` |
| `IA_` · `IMC_` | 입력 액션 · 입력 매핑 컨텍스트 | `IA_Select` |

텍스처 뒤 글자: `_D` 색(Base Color) · `_N` 노멀 · `_ORM` AO·러프니스·메탈릭 묶음 · `_E` 발광 · `_M` 마스크

## C++ 폴더

`Source/CozyRealm/` 아래도 기능별로 나눈다: `Core/`(게임 모드·컨트롤러) · `Camera/` · 이후 `Facility/` · `Production/` · `Data/` · `UI/` · `Debug/`

## 시설·장식 메시 갈아 끼우기 (CSV에 경로만 · 출시 수정 2차 2026-10-30)

코드를 고치지 않고 CSV에 메시 경로만 적으면 회색 상자 대신 그 메시가 뜬다. 칸이 비어 있으면 지금처럼 회색 상자(장식은 임시 도형).

1. 메시를 `Content/CozyRealm/Facilities/<시설>/` (장식은 `Content/CozyRealm/Decor/`)에 `SM_` 이름으로 넣는다. 이 두 폴더는 패키지에 항상 들어간다(`DefaultGame.ini` DirectoriesToAlwaysCook). 다른 폴더에 두면 패키지에서 메시가 빠져 회색 상자로 보인다.
2. 콘텐츠 브라우저에서 메시를 오른쪽 클릭 → **Copy Reference** → 경로 부분(`/Game/...SM_Mill_A.SM_Mill_A`)만 CSV 칸에 붙인다.
   - 시설: `Data/GameData/Facilities.csv`의 `MeshStage1`(외형 1단계) · `MeshStage2` · `MeshStage3` — 빈 단계는 낮은 단계 메시를 쓴다.
   - 장식: `Data/GameData/Decorations.csv`의 `Mesh`.
3. 크기·위치 맞추기 (같은 CSV의 칸)
   - `bFitMeshToCells` True(기본): 메시 바닥 크기를 차지 칸(`Size`)에 맞춰 비율 그대로 늘이고 줄인다. False면 메시 원래 크기.
   - `MeshScale`: 맞춘 뒤 추가 배율 (1 = 그대로).
   - `MeshOffset`: 위치 보정 cm, 예 `(X=0,Y=0,Z=-5)`. 피벗이 어디에 있든 메시 바닥 가운데가 칸 가운데 지면에 오게 이미 맞추므로 보통 0.
   - `MeshYaw`: 방향 보정(도). 정면이 카메라 쪽(-X)을 보도록 90 · 180 등.
4. 게임을 다시 켜면 적용된다(CSV는 시작할 때 읽음). 경로를 잘못 적으면 로그에 `[시설 메시] … 읽지 못해 회색 상자로 둡니다`가 남고 회색 상자로 보인다.

참고: 클릭 판정은 보이지 않는 회색 상자가 그대로 맡는다(메시 충돌 설정과 상관없음). 폴리곤 예산은 위 '아트' 규칙(시설 5천 · 소품 1,500 tri)을 따른다.

## 소리 연결 (출시 수정 2차)

- 효과음·배경음 파일은 `Content/CozyRealm/Audio/` 아래에 `S_` 이름으로 넣는다 (이 폴더도 항상 쿡).
- 연결은 `Config/DefaultGame.ini` `[/Script/CozyRealm.CozyAudioSettings]` (프로젝트 설정 → Cozy Audio):
  - `+EventSounds=(Harvest, "/Game/CozyRealm/Audio/SFX/S_Harvest.S_Harvest")` — 종류: Harvest(수확·수령) · ProcessingDone(가공 완료) · UpgradeDone(업그레이드 완료) · Sale(판매) · PlacementConfirmed(배치 확정) · Purchase(구매·바닥 칠하기) · ResidentAssigned(주민 배치)
  - `EstateMusic=` · `TitleMusic=` — 반복 재생은 사운드 에셋의 Looping을 켠다.
- 효과음은 Sound Class를 `SC_SFX`, 배경음은 `SC_Music`으로 두면 설정 창 음량 슬라이더를 따른다. 비워 두면 무음으로 동작한다.
