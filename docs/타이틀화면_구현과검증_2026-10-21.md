## 조사 결과 (Claude · 구현 전)

- 시작 맵은 `L_Estate`, 전역 게임 모드는 `CozyRealmEstateGameMode`였다. 이 게임 모드의 `StartPlay`가 `StartEstate`를 불러 저장 불러오기 → 방치 정산 → 즉시 저장을 한다. 타이틀이 같은 게임 모드를 쓰면 들어가기만 해도 정산·저장이 일어나므로 **타이틀 전용 게임 모드**가 필요했다.
- `UCozyEstateSubsystem`은 모든 맵에 생기는 월드 서브시스템이다. 하지만 `StartEstate`를 부르지 않으면 Tick은 저장 대기열만 확인하고 끝나며, `Deinitialize`도 시작한 경우에만 저장한다.
- **위험:** 설정 창의 '게임 종료'(`ConfirmQuit`)는 `SaveEstate`를 부르는데, `SaveEstate`에는 영지 시작 여부 검사가 없었다. 타이틀에서 누르면 빈 상태로 실제 저장(`CozyRealm_Slot1.sav`)을 덮어쓸 수 있었다.
- 불러오기 실패(손상·미래 버전)는 `bSaveBlockedByInvalidFile`로 저장을 막고 새 영지를 보여 준다. 실패를 밖에서 알 방법은 문구뿐이었다. 저장을 지우거나 새 게임으로 초기화하는 API는 없었다.
- 설정은 게임 인스턴스 서브시스템이라 맵이 바뀌어도 유지된다. 설정 화면 `WBP_Settings`의 값 변경 동작은 어디서나 되지만 '창 닫기'는 영지 HUD가 있어야 동작했다.
- Content 안에 키아트·로고 그림은 없다. 대신 벚꽃 아이콘 `T_Cozy_Sakura_v2`, 신사 아이콘이 있다. `docs/images`의 그림은 설명용 인포그래픽이라 배경으로 맞지 않는다.

## 설계 (Claude 제안·구현 · 사용자 최종 검토 미확인)

- **배경 = 실제 게임 화면 재사용:** 새 그림을 만들지 않았다. 타이틀 맵 `L_Title`은 비어 있고, 실행할 때 실제 영지 맵 `L_Estate`의 풍경만 불러와 천천히 움직이는 카메라로 보여 준다. 시설·주인공은 영지를 시작해야 생기므로 나오지 않는다.
- **임시로 구분할 것:** 글자 로고 "CozyRealm"(정식 제목 미정이라 작업명), 부제 "벚꽃 신사가 있는 작은 마을"(Claude가 정한 임시 문구), 버전 `0.3.0 개발판`(임시 번호).
- **타이틀에서 영지를 시작하지 않음:** `CozyTitleGameMode`는 `StartEstate`를 부르지 않는다. 따라서 저장 생성·방치 정산·생산이 없다.
- **안전장치:** `SaveEstate`는 영지를 시작하기 전에는 저장하지 않는다. 설정 창 '게임 종료'는 영지가 시작되지 않았으면 저장 없이 바로 종료한다.
- **저장 상태 확인(읽기만):** `UCozyEstateSubsystem::ProbeSaveFile`이 아래 넷 중 하나를 알려 준다. 파일을 만들거나 고치지 않는다.
  - 없음
  - 정상
  - 직전 정상본으로 복구 가능
  - 읽을 수 없음
- **버튼 구성:**
  - 저장이 있으면(읽을 수 없는 경우 포함): 이어하기(금색 · 맨 위 · 기본 선택) / 새 게임 / 설정 / 게임 종료
  - 저장이 없으면: 새 게임(금색 · 기본 선택) / 설정 / 게임 종료
- **새 게임:** 저장이 있으면 확인 창을 띄운다. 기본 선택은 '취소'다. 확인하면 `ArchiveSaveForNewGame`이 기존 파일(`Slot1.sav`, `_previous.sav`, `.pending`)을 `SaveGames/Backup_NewGame_<UTC>/`로 옮긴다. 먼저 모두 복사한 뒤에만 원본을 옮기고, 지우지는 않는다. 그 뒤 영지 맵에 들어가며, 영지는 기존 규칙대로 새 영지를 만든다.
- **불러오기 실패:** 이어하기를 누르면 오류 창에 '다시 시도'와 '닫기'가 나온다. 새 게임으로 대신하지 않고, 파일도 그대로 둔다.
- **마을 입장:** 버튼을 모두 끄고 화면 전체를 덮는 '마을로 가는 중…' 창을 띄워 중복 클릭을 막는다. 20초 안에 맵이 열리지 않으면 안내를 띄우고 다시 누를 수 있게 한다.
- **설정:** 게임 안 설정 화면 `WBP_Settings`를 그대로 띄운다. '창 닫기'를 누르면 `UCozyUiScreen::OnCloseRequested` 알림으로 타이틀이 닫는다. Esc를 누르면 열린 확인 창을 먼저 취소하고, 없으면 설정 창을 닫는다.
- **게임 종료:** 확인 창(기본 선택 '취소') → 종료. 타이틀에서는 저장하지 않는다.
- **조작:**
  - 마우스: 올리면 그 버튼이 선택된다.
  - 키보드: 위/아래·W/S 이동, Enter/Space 실행, Esc 종료 확인(확인 창에서는 취소), 확인 창 안에서는 왼쪽/오른쪽·A/D 이동.
  - 상태 표시: 선택은 벚꽃 표시 + 5% 확대 + 주홍 글자다. 마우스 올림·누름은 테마 버튼 이미지(Hover·Pressed)가 따로 보여 준다.
- **글자 가독성:** 왼쪽에 짙은 그림자 그라데이션을 깔고, 그 위 종이 패널에 버튼을 올린다. 로고·상태·버전 글자에는 그림자를 넣었다.
