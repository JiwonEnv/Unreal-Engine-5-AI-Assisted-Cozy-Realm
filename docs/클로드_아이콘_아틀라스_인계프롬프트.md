# 클로드에게 전달할 프롬프트

CozyRealm의 최신 로컬 작업 상태를 아래 내용으로 갱신해줘. PR #36 이후 Codex가 진행한 아이콘 작업이며, 현재 파일을 출발점으로 삼아줘. 이 메시지는 맥락 인계 요청이다. 임의로 재구현하거나 커밋·푸시·병합·에셋 삭제하지 말고, 먼저 실제 파일과 기록을 확인해 한국어로 이해한 내용을 보고해줘.

사용자 요청은 새로 추가된 팥·쌀·쌀가루·잠금·미리보기 아이콘을 기존 밀·밀가루의 따뜻한 그림풍에 맞추고, 기존 아이콘까지 종류별 공유 텍스처로 묶는 것이었다. 이미지 제작과 구현은 Codex가 했다. 사용자 디자인 최종 승인과 혼동하지 마.

구현 결과:
- 그림 21개를 자원 384×384, 시설 512×256, 기타 256×256의 텍스처 3장으로 묶었다. 각 칸은 128×128, 그림 최대 112×112이며 최소 8픽셀 투명 여백을 둔다.
- 활성 테마 DA_UiTheme_CozyVillage의 AtlasImages에 기존 아이콘 이름 35개를 유지했다. 화면에서는 기존처럼 Icon.Wheat, Facility.Mill, Menu.@Row 등을 고르면 된다. 배경 Images 5개와 버튼·게이지 스타일은 유지했다.
- FCozyUiAtlasImage의 Texture, TextureSize, Origin, Size, Tint로 영역을 기록하고, FindImage가 같은 텍스처를 참조하는 FSlateBrush의 UV 영역을 만든다. 개별 텍스처로 다시 잘라 가져오는 방식이 아니다. Paper2D나 아이콘별 머티리얼도 추가하지 않았다.
- TextureSize는 원본 시트 전체 크기다. 편집기 초기 로딩 중 임시 텍스처 크기나 플랫폼 해상도 축소가 영역 계산을 깨뜨리지 않게 저장한다. 이미지 맞춤 계산은 잘라낸 영역의 ImageSize를 사용한다. 이름 선택 목록과 기존 Images 호환성을 유지했다.

원본 수정 후 일반 Python의 pack_icon_atlases.py로 시트를 다시 만든 다음, 플레이를 종료하고 언리얼 명령란에서 아래를 실행한다:
py E:/Project/UE5_CozyRealm/CozyRealm/SourceArt/UI/CozyTheme/import_icon_atlases.py
이 도구가 시트 3장과 테마 좌표를 함께 저장하며 기존 이름별 Tint를 보존한다. 새 그림 원본은 Painted에 있고 기존 개별 PNG·텍스처 에셋은 보존했다.

검증: 정식 CozyRealmEditor 빌드 성공. SharedRegions와 ActiveTheme 자동 검증 2개 모두 통과했고 편집기 재실행 직후에도 다시 통과했다. 실제 HUD·창고·제분소 메뉴, 진행 중 미리보기 창 8개의 캡처를 확인했다. 시험 저장 파일은 백업과 SHA256이 동일하게 복원했다. Python 위젯 기하 검사에는 유효한 대상이 없어 ‘텍스트 초과 0건’ 검증으로 사용하지 않았다. 이전 48개 상태 검사를 이번에 다시 했다고 기록하지 마.

RGBA8·밉맵 없음 조건의 픽셀 용량 계산은 11.25MiB→1.3125MiB이며 공유 시트와 해상도 조정의 합산 효과다. 실제 GPU 메모리·그리기 횟수·성능·패키지 용량은 미측정이다. 옛 텍스처는 남아 있어 패키지에서 빠진다고 보장할 수 없다. 잠금·미리보기 그림은 현재 사용 화면이 없어 실제 적용 화면 검증 대상이 아니다.

이번 작업은 글꼴·HUD 위치·보라색 OnPoint·제작 및 업그레이드 규칙을 변경하지 않았다. 기존 사용자/Claude/Codex 변경이 섞여 있으므로 파일 전체를 되돌리거나 전부 이번 작업으로 취급하지 마. 현재 작업은 로컬이며 이번 작업의 커밋·PR·병합·노션 갱신·Windows 플레이 녹화는 수행하지 않았다. 캡처를 녹화로 기록하지 마. 추후 노션 완료 기록을 남길 때는 AGENTS.md에 따라 실제 게임 화면 녹화를 확인한 뒤 기록해줘.
