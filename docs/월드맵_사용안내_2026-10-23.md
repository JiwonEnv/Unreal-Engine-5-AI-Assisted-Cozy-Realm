# 산 월드 사용 안내 · 레벨 초안 검증 완료

2026-10-24 기준, 실제 맵 생성·에디터/게임 빌드·패키지 실행·구역 이동·보행 시연·게임 화면 녹화를 확인했다. 현재 결과물은 구역과 동선을 검토하는 레벨 초안이다. 세부 이력은 `월드맵_제작_진행기록_2026-10-23.md`를 참고한다.

## 만들고 있는 것

큰 산의 중턱에 시작 영지를 두고, 서쪽·동쪽 확장 후보지와 상부 능선, 남쪽 산기슭을 흙길로 연결하는 504m 규모의 레벨 초안이다. 구역 위치·면적·시설 배치는 Codex 제안이며 확정 기획이 아니다. 기존 시설의 로우폴리 형태를 실제 크기로 배치해 공간을 검토한다.

이번 맵에서 산의 몸체, 건설 후보 평지, 올라가는 흙 경사길은 모두 **하나의 Landscape**다. 길은 별도로 얹은 경사로 모델이 아니라 땅의 높이를 연결하고 흙 재질을 칠한 구간이다. 모델은 시설·나무·바위·절벽 장식에 사용했다. 따라서 평지와 경사길 사이에 서로 다른 땅 모델의 이음매를 맞출 필요가 없다. 다만 돌출 절벽 장식과 지면의 최종 아트 연결, 바닥 텍스처는 후속 다듬기가 필요하다.

`Clearings`와 `Routes`는 지형 생성기에 주는 설계 수치다. 생성 후 화면에 있는 땅 자체는 일반 Landscape라서 직접 조형할 수도 있다. 수치로 재생성하는 방식과 직접 조형한 결과 중 어느 쪽을 원본으로 관리할지 정한 다음 편집한다. 이번 초안은 수치와 스크립트를 원본으로 관리했다.

## 언리얼에서 여는 위치

콘텐츠 브라우저 `Content > CozyRealm > Maps > L_MountainWorld`를 두 번 눌러 연다. 위쪽 재생 버튼을 누르면 새 월드 검토 모드로 들어간다. 원래 `L_Estate`, 타이틀의 진입 맵과 저장 파일은 별도로 유지한다.

플레이는 새 맵에 지정된 `CozyWorldExplorerMode`로 실행한다. 기존 영지 저장을 읽거나 자동 저장하지 않는다. 이 모드의 시설은 공간 검토용 Static Mesh이며 생산·업그레이드되는 기존 시설 액터가 아니다. 기존 브러시·바닥·건설 기능을 월드 전체에 연결한 것으로 해석하지 않는다.

에디터 없이 먼저 구경하려면 `E:/Project/UE5_CozyRealm/output/MountainWorldBuild/월드맵_실행.cmd`를 두 번 누른다. 원본 저장과 분리된 검토 폴더를 사용한다. Windows가 네트워크 접근 허용을 물으면 이 로컬 검토에 허용은 필요 없다. 설정을 변경하지 않고 검토했다.

## 검토 모드 조작

| 입력 | 역할 |
|---|---|
| W/A/S/D | 실제 지면 충돌을 따라 걷기 |
| 마우스 | 카메라 방향·각도 |
| 휠 | 카메라 확대·축소 |
| M | 전체 지도 보기 / 직전 걷던 위치로 복귀 |
| 1~5 | 표 순서대로 구역으로 이동 |
| F6 | 현재 카메라 앞쪽으로 3초 실제 보행 시연 |

처음에는 `M`으로 전체 산과 길을 본 뒤 `1`로 시작 영지, `2`와 `3`으로 확장 후보지, `4`로 위쪽 능선, `5`로 산기슭을 확인하면 된다. 가까워서 시설이 잘리면 휠로 멀리 본다. 가운데 흰 타원은 실제 캐릭터 대신 놓은 140cm 크기 기준이다.

숫자 이동은 레벨 검토용 순간 이동이다. 실제 게임의 구역 이동 또는 해금 기능을 뜻하지 않는다. 지도 보기 상태에서는 걷기가 멈춘다. 별도 실행 파일은 `Alt+F4`로 닫는다.

`F6`는 지면 충돌과 이동을 확인하기 위한 검토 도구다. 이동 컴포넌트가 3초 동안 실제로 걸으며 결과를 실행 로그에 남긴다. 전체 지도에서는 시작하지 않으며, 구역 이동이나 전체 지도 전환으로 중단한다. NPC 자동 길찾기 기능은 아니다.

## 수정하는 곳

- 아웃라이너 `산월드_구역과동선`: `Clearings`에서 구역 중심·높이·반지름, `Routes`에서 길의 경유점·폭·주변 연결 폭을 수정한다. 단위는 cm다. 각 중심 Z는 시작 영지 기준 상대 높이다.
- 높이·구역·길을 변경한 뒤 기존 `지형 새로 만들기`를 실행하면 Landscape를 재생성한다. 재생성하면 Landscape 모드에서 직접 조형·칠한 내용은 덮어쓴다. 직접 조형하기 전 맵을 다른 이름으로 복제해 둔다.
- 재생성 직후 시설·자연물의 높이는 이전 위치에 남는다. 에디터에서 Python 스크립트 실행으로 `SourceArt/WorldMap/refresh_world_scenery.py`를 실행하면 기존 배치를 새 레이아웃 높이에 맞추고 새 길·평지에 겹친 장식을 제거한다. 자동 저장하지 않으므로 화면을 확인하고 맵을 저장한다. 이번 제작에서 실행 검증했다. 손으로 조형한 높이가 아니라 레이아웃 수치로 계산한 높이를 기준으로 한다.
- `Mountain_Landscape_504m`: 일반 Landscape이므로 Landscape 모드에서 조형·재질 칠하기가 가능하다.
- 폴더 `20_시설_검토배치`: 시설의 위치·회전·배율을 개별 수정한다. 기준 크기는 원본 Blender의 미터 치수를 UE의 cm 단위로 가져온 결과다.
- 자연물은 레이아웃 액터의 HISM 네 묶음(넓은잎나무·소나무·바위·절벽조각)으로 저장한다. 검토용 장식이며 현재 별도 보행 충돌을 켜지 않았다. 실제 보행 기반은 Landscape다.
- 시설·자연물 메시와 임시 색 재질: `Content > CozyRealm > Environment > MountainWorld`.

## 자동 생성 원본

- C++ `Environment/CozyMountainWorld`: Landscape 높이·재질 가중치 규칙.
- `SourceArt/WorldMap/build_mountain_world.py`: 새 맵의 메시 임포트, 자연물·시설·조명 배치. 이미 있는 산 월드는 자동 덮어쓰지 않는다.
- 저장된 시설 원본 Blender에서 사본을 내보내는 스크립트: 저장소 루트 `Art/WorldMap/export_world_assets.py`. 사용자 Blender 세션의 미저장 수정은 사본에 반영되지 않는다.
