# 지형 제작 방식 추가 설명

2026-10-21 사용자 요청에 따라 Codex가 내장 이미지 생성 도구로 설명도 2장을 추가했다. 사용자 확정 설계 또는 실제 완성 맵을 뜻하지 않는다. 게임 코드·레벨·에셋과 노션은 수정하지 않았다.

- `03_랜드스케이프와_절벽메시_제작제안.png`: 큰 산과 평지·흙 경사길은 Landscape로 이어 만들고, 급경사 옆면은 재사용 가능한 절벽 메시로 보완하는 AI 제안. 경계의 형태·재질·충돌을 별도로 맞춰야 한다. 예시의 정자·수목·절벽 키트가 현재 프로젝트에 있다는 뜻이 아니다.
- `04_공통표면과_이동경로_역할.png`: 현재 공통 표면 조회 및 영지 범위 자체 격자 경로 탐색의 역할을 설명한다. A/B 고유 ID는 구분되며 조회 방식만 공유한다. 그림의 지형은 설명용이다. 완성 언덕 모델·경계 자동 보정 기능은 아니다.
- `추가설명_생성프롬프트.json`: 생성 도구에 전달한 원문. 최종 디자인 승인과 구분한다.

## 외부 실제 시연 출처

1. Epic 공식 Landscape 조형 시연(UEFN): https://dev.epicgames.com/documentation/en-us/fortnite/sculpting-the-terrain-in-unreal-editor-for-fortnite
   - 산·언덕·고원을 조형하는 실제 시연이다. CozyRealm 게임 화면이 아니며 UEFN 문서다.
2. Epic 공식 Landscape Splines(UE5.8): https://dev.epicgames.com/documentation/en-us/unreal-engine/landscape-splines-in-unreal-engine
   - 곡선을 편집해 지형 높이·길을 수정하고 선택적으로 메시를 배치하는 제작 도구. 캐릭터의 경로 탐색과 다른 기능이다.
3. Epic 공식 RVT Quick Start(UE5.8): https://dev.epicgames.com/documentation/unreal-engine/runtimevirtual-texturing-quick-start-in-unreal-engine
   - Content Examples에서 도로 스플라인 재질을 Landscape로 합성하는 전후 비교. 돌 메시의 경계 혼합과 같은 결과라고 일반화하지 않는다. RVT는 현재 프로젝트 구현 완료가 아닌 추가 선택지다.
4. M4 제작자 RVT 지형·오브젝트 경계 혼합 사례: https://aaronneal.online/docs/m4/runtime-virtual-texturing/rvt-terrain-blending-for-objects/
   - 바위 메시와 땅의 재질 경계를 섞는 실제 사진·영상. 특정 상품 도입을 권하는 의미가 아니다.

웹 도구에서 공식 문서 본문과 이미지 링크는 확인했으나 일부 원본 이미지 응답은 접근 오류였다. 원문 페이지 링크도 함께 제공해 비교 자료를 직접 확인할 수 있게 한다. 외부 이미지를 로컬로 내려받지 않았다.
