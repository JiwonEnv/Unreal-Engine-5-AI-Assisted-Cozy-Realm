# 지형 편집기 구현 예정안 · 2026-10-27

사용자 요청: 구현 전에 기능을 이미지로 정리하고, 특정 산 월드에 종속되지 않는 편집 창의 구성을 확인한다.

두 이미지는 내장 이미지 생성 도구로 만든 설명용 구성안이다. 실제 언리얼 화면이나 구현 완료 증거가 아니다. 기존 게임 코드·맵·프로젝트 설정은 이번 이미지 작업에서 변경하지 않았다.

## 화면 구성안

파일: `01_편집기_화면구성안.png`

현재 열린 레벨의 지형을 대상으로 위에서 보는 지도와 3D 미리보기를 연결한다. 왼쪽에는 선택·평지·산/능선·연결 길 도구를, 오른쪽에는 선택한 구역의 이름·높이·가로·세로·주변 연결 범위를 배치한다. 높이 색상·등고선·경사·지형만 보기로 지형을 읽고, 손잡이와 미터 단위 수치로 편집한다. 하단에는 되돌리기·미리보기·사본 저장·지형 적용을 둔다.

## 기능과 작업 순서

파일: `02_기능과작업순서.png`

전체 지형 읽기, 평지 만들기, 산/능선 조절, 길 연결, 확인 후 적용, 다른 맵에서 사용의 여섯 기능을 정리했다. 설정 저장·불러오기로 구역·산·길의 설정을 재사용하는 방향이다.

기본 순서: 구역 배치 → 높이·모양 조절 → 길 연결 → 미리보기 → 사본 저장 → 실제 지형에 적용.

## 이미지 해석 범위

- 배경의 건물·숲·강·폭포는 화면을 설명하기 위한 장면 예시다. 이 그림과 같은 완성된 아트 맵을 자동 생성하는 기능으로 해석하지 않는다.
- 산·평지·흙 경사길은 Landscape로 만든다. 그림의 다리·건물·바위는 별도 모델을 사용한 배치 예시다. 길 편집으로 다리 모델까지 자동 생성하는 범위는 확정하지 않았다.
- 다른 레벨에서도 편집 창을 열어 쓰는 것이 목표다. 기존 지형 선택과 새 지형 생성의 지원 범위, 대형 분할 월드·외부 지형 형식 지원은 실제 구현에서 확인해야 한다.
- 사본 보존·복구·되돌리기·기존 수동 조형의 보존 방식도 구현·검증이 필요한 예정 기능이다.
- 구체적인 배치·수치·화면 구성은 AI 제안이다. 사용자 최종 승인이나 구현 완료로 기록하지 않는다.

## 생성 지시문 요약

생성 방식: 내장 이미지 생성 도구, 신규 이미지 두 장, 참조 이미지 없음, 불투명 배경.

첫 이미지: 한국어 초보자를 위한 언리얼 지형 편집기 화면 구성안을 가로형으로 그린다. 구현 예정안을 명시한다. 이름이 고정된 맵이 아닌 현재 열린 레벨을 대상으로 한다. 어두운 언리얼 계열 UI에 선택·평지·산/능선·연결 길, 지도와 3D 미리보기, 높이별 색상과 등고선, 선택 구역의 조절 손잡이, 높이 +12m·가로 40m·세로 30m·주변 연결 8m 설정을 보여준다. 되돌리기·미리보기·사본 저장·적용 버튼을 구분한다. 작은 기술 정보로 화면을 채우지 않는다.

둘째 이미지: 밝은 배경의 한국어 기능 설명 그림을 가로형으로 그린다. 구현 예정안을 명시한다. 여섯 칸에 지형 읽기·평지·산/능선·길·미리보기/사본 저장/적용·다른 맵에서 재사용을 작은 지형 장면과 함께 보여준다. 조절 전후, 높이 화살표, 폭 손잡이, 길 경유점과 급경사 표시를 사용한다. 하단에는 작업 순서와 Landscape/별도 모델의 역할을 표시한다. 큐브 타일 지형과 게임 생산 기능의 구현 완료 표시는 넣지 않는다.
