# 설정 메뉴 사용 안내 (사운드 · 화면 · 게임 종료)

2026-10-17 · Claude 구현 · 브랜치 `feat/settings-menu`

HUD 오른쪽 위 **설정** 버튼(벚꽃 아이콘 · 예전 '메뉴' 버튼 자리 그대로)을 누르면 설정 창이 열린다.
개발용 디버그 창은 지금처럼 **F1**로 따로 연다.

---

## 1. 창 구성

| 부분 | 내용 |
|---|---|
| 탭 | **사운드** · **화면** (한 번에 한 탭만 보임 · 탭 내용이 길면 그 부분만 스크롤) |
| 사운드 탭 | 전체 음량 · 배경음 · 효과음 슬라이더(0~100)와 숫자 · 소리 연결 안내 |
| 화면 탭 | 지금 적용된 값 · 화면 모드(전체 화면 / 테두리 없는 창 / 창 모드) · 해상도(◀ ▶) · 수직 동기화 · 최대 프레임(30 / 60 / 120 / 제한 없음) |
| 아래 버튼 줄 (항상 보임) | **적용** · **변경 취소** · **이 탭 기본값 복원** · **게임 종료** · **닫기** |
| 확인 창 (아래에 고정) | 화면 변경 유지 확인(15초) · 게임 종료 확인 · 저장 실패 안내 |

## 2. 동작 규칙

- **적용 전에는 저장하지 않는다.** 슬라이더를 움직이면 소리는 바로 바뀌지만(미리 듣기), '적용'을 눌러야 저장된다.
- **변경 취소** = 이 탭에서 적용하지 않은 변경을 저장된 값으로 되돌림.
- **닫기 · Esc** = 창을 닫으면서 적용하지 않은 변경은 모두 버림 (토스트 '적용하지 않은 설정 변경은 취소했습니다').
- **이 탭 기본값 복원** = 지금 탭만 기본값으로 바꿔 둠 (적용을 눌러야 저장 · 게임 진행 데이터는 건드리지 않음).
  - 사운드: 전체 · 배경음 · 효과음 모두 100
  - 화면: 테두리 없는 창 · 모니터 해상도 · 수직 동기화 켬 · 최대 프레임 60
- **화면 모드 · 해상도를 적용하면** 바로 바뀌고 "이 설정을 유지할까요?"가 뜬다.
  - **유지** → 저장 · **되돌리기** 또는 **Esc** → 이전 설정으로 · **15초 동안 아무것도 안 하면** → 이전 설정으로 자동 복원
  - 확인 전에는 파일에 저장하지 않는다 (그 사이 게임이 꺼져도 이전 설정이 남음)
  - 수직 동기화 · 최대 프레임만 바꾼 경우에는 확인 없이 바로 저장
- **테두리 없는 창**은 모니터 해상도를 그대로 쓰므로 해상도 ◀ ▶가 꺼지고 이유가 표시된다.
- 해상도 목록: 전체 화면 = 모니터가 지원하는 해상도(1280×720 이상) · 창 모드 = 1280×720 · 1366×768 · 1600×900 · 1920×1080 · 2560×1440 · 3840×2160 중 모니터보다 작은 것
- **Esc 순서**: 확인 창(화면 변경 · 게임 종료 · 저장 실패)이 떠 있으면 그 확인부터 취소 → 다시 Esc를 누르면 설정 창을 닫음
- **게임 종료**: "게임을 종료할까요?" → **종료** = 영지를 저장(`SaveEstate`)한 뒤 종료 · 저장에 실패하면 종료하지 않고 안내 + **다시 시도 / 취소**
  - 패키지 게임은 프로그램이 닫히고, 에디터 플레이(PIE)에서는 플레이만 끝난다 (에디터는 그대로)
- 설정 창이 열려 있어도 생산 시간은 계속 흐른다 (다른 창과 같음 · 게임을 멈추지 않음).
- 설정 창을 열고 닫기만 해서는 영지 진행 저장(`.sav`)도, 설정 파일도 바뀌지 않는다.

## 2-1. 작은 창 모드 (2026-10-18)

- HUD 오른쪽 위 **작은 창** 버튼 또는 **M** 키 → 게임 화면 640×360 창이 되어 모니터 작업 영역(작업 표시줄 제외)의 오른쪽 아래 구석(여백 16)에 붙는다. 영지 화면은 그대로 보이고 생산은 계속 흐른다.
- 작은 창에서는 간단한 HUD만: 시계 · 전부 수확 · **크게 보기** (다시 누르거나 M → 들어가기 전 크기·위치·화면 모드로)
  - 시설 클릭 메뉴 · 창(창고 I · 주민 Tab) · 배치(B) · 디버그 창(F1) · 설정 창은 작은 창에서 막힘 (크게 보기 후 사용)
- **작은 창 항상 위**: 설정 → 화면 탭 마지막 줄 (기본 끔 · 적용을 눌러야 저장 · 켜면 작은 창일 때만 다른 프로그램 창 위에 뜸)
- 화면 설정 파일은 바꾸지 않는다: 창 모드에서 창 크기를 바꾸면 엔진이 그 크기를 해상도 설정에 써 넣으므로, 들어가기 전 값을 기억했다가 나올 때(그리고 작은 창인 채로 종료할 때) 되돌린다.
- 에디터 뷰포트 안 플레이에서는 쓸 수 없음(에디터 창을 줄이지 않음) · 새 창 플레이(PIE)와 실행 파일에서 사용
- 편집할 곳
  - 크기 640×360 = `CozySettingsSubsystem.h`의 `CompactWidth` · `CompactHeight` · 구석 여백 = `PlaceCompactWindow`
  - 작은 창에서 보일 HUD 요소 = `DA_UiScreen_HUD` → '4 작은 창'의 **Compact Elements**(작은 창에서도 보임: Clock · CollectAll) · **Compact Only Elements**(작은 창에서만: Expand)
  - HUD 버튼 = `DA_UiScreen_HUD`의 요소 `Compact`(작은 창) · `Expand`(크게 보기) · 동작 Toggle Compact Window
  - 다른 화면에도 같은 규칙을 쓸 수 있음 (화면 설정의 '4 작은 창' 칸)

## 3. 저장 위치 (영지 진행과 분리)

| 무엇 | 파일 |
|---|---|
| 설정 (음량 · 화면) | `GameUserSettings.ini` — 에디터: `CozyRealm/Saved/Config/WindowsEditor/` · 패키지 게임: `<게임 폴더>/CozyRealm/Saved/Config/Windows/` |
| 영지 진행 | `SaveGames/CozyRealm_Slot1.sav` (설정 창은 '게임 종료'에서만 기존 저장 절차로 저장) |

`GameUserSettings.ini` 안의 구역:
- `[/Script/CozyRealm.CozyGameUserSettings]` → `MasterVolume` · `MusicVolume` · `SfxVolume` (0~1) · `bCompactAlwaysOnTop` (작은 창 항상 위)
- 화면 값은 엔진 기본 키 (`FullscreenMode` · `ResolutionSizeX/Y` · `bUseVSync` · `FrameRateLimit` · `LastConfirmed…`)

키트에 새로 생긴 것 (다른 창에서도 쓸 수 있음):
- 요소 종류 **Slider (슬라이더)** — Value의 비율로 손잡이 위치 · 움직이면 Action에 0~1 비율을 넘김
- 값 `Settings*` · 목록 `Settings*Page / SettingsConfirm / SettingsQuitAsk / SettingsQuitFailed` (조건이 맞을 때만 한 줄) · 동작 `OpenSettings` ~ `ConfirmQuit`

## 5. 소리 연결 (지금은 배경음 · 효과음이 없음)

- 음량은 사운드 믹스 **`Audio/SM_CozyVolume`** 하나로 사운드 클래스 3개의 음량을 바꾼다.
  - `SC_Master` (전체) · `SC_Music` (배경음 · 부모 SC_Master) · `SC_SFX` (효과음 · 부모 SC_Master)
  - 실제 음량: 배경음 = 전체 × 배경음 · 효과음 = 전체 × 효과음
- 연결 위치: **프로젝트 설정 → Cozy Audio (소리 연결)** (`DefaultGame.ini [/Script/CozyRealm.CozyAudioSettings]`)
- **새 배경음**: 사운드 웨이브(또는 사운드 큐)의 `Sound Class` → `SC_Music`
- **새 효과음**: `Sound Class` → `SC_SFX` · 비워 두면 프로젝트 기본 사운드 클래스(`DefaultEngine.ini [/Script/Engine.AudioSettings] DefaultSoundClassName = SC_SFX`)를 따름
- 게임을 시작할 때(플레이어 컨트롤러 BeginPlay) 저장된 음량을 적용한다.
- ⚠️ 2026-10-17 기준 게임에 소리가 하나도 없어서, **귀로 들어서 확인한 것은 없다.** 믹스 · 클래스 연결과 저장 값만 확인했다.

## 6. 확인 방법 (요약)

- PIE: 설정 창 열기 · 탭 · 슬라이더 · 적용 · 변경 취소 · 다시 열기 · 확인 창 유지/되돌리기/15초 · 종료 취소 · 저장 실패(저장 파일 읽기 전용) · 저장 후 종료
- 패키지 게임: 전체 화면 / 테두리 없는 창 / 창 모드 전환 · 해상도 · 재실행 후 유지 · Esc 순서 · 정상 종료
- 시험 전 `SaveGames/*.sav`와 `GameUserSettings.ini`를 복사해 두고, 끝나면 되돌린 뒤 해시를 비교한다.
