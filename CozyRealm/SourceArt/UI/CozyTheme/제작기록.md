# UI 그림 제작 기록

사용자의 2026-10-05 마을 컨셉과 가공 창 참고 이미지의 분위기를 근거로 만든 적용안이며 최종 승인 전입니다.

그림 아이콘은 내장 이미지 생성 도구로 만들었습니다. 생성 요청은 다음과 같습니다.

> 따뜻한 일본풍 작은 정령 마을 게임에서 사용할 투명 배경 4열 4행 아이콘 시트. 귀여운 손그림과 짙은 갈색 윤곽, 크림색·황금색·남색 기와·분홍 벚꽃. 밀 이삭, 밀가루 포대, 금화, 시계, 신사, 물레방아 제분소, 주민 숙소, 업그레이드 작업소, 밭 관리 창고, 밭, 판매 가게, 창고, 푸른 불꽃 정령, 부적, 별 조각, 벚꽃. 글자와 격자선은 넣지 않고 각 그림을 독립적으로 사용할 수 있게 만든다.

CozyIconAtlas.png는 생성 원본입니다. T_Cozy_이름.png는 개별 교체용 원본입니다. 각 칸 가장자리의 인접 그림 잔여 선을 정리한 텍스처를 v2 에셋으로 가져왔습니다. 그림에 글자나 클릭 동작을 합치지 않았습니다.

패널과 버튼 배경은 크림색·푸른색·금색의 단순한 둥근 상자와 그라데이션으로 따로 제작했습니다. 글자는 언리얼에서 표시합니다.

주아 글꼴은 Google Fonts 공식 저장소의 Jua-Regular.ttf를 사용했습니다. Fonts/OFL-Jua.txt에 배포 라이선스를 함께 보존했습니다.

수정 방법과 검증 범위는 저장소 docs/UI_마을테마_수정안내.md에 있습니다.
