# 지형 편집기 · 첫 버전

언리얼 5.8용 제작 도구다. 플레이어가 실행 중 땅을 바꾸는 기능과는 별개다.

## 시작

플러그인 빌드 후 에디터를 다시 실행하면 **창 → 지형 편집기**에서 연다. 콘솔에서는 `Cozy.TerrainEditor`로 연다. 이미 열어 둔 에디터에는 새 모듈이 자동으로 나타나지 않을 수 있다. 작업 중인 맵을 먼저 저장하고 직접 재실행한다.

1. 원하는 레벨을 열고 **새 설계**를 누른다. 별도 지형 도구를 열기 전에 Landscape를 만들 필요는 없다.
2. **평지 추가**, **산 추가**, **길 그리기**로 지도에서 추가한다. 평지·산은 드래그로 이동하고 사각 손잡이로 크기를 바꾼다. 길은 점을 찍어 만들고 선택 모드에서 경유점을 옮긴다.
3. 오른쪽 **선택 높이**, **가로·세로**, 전체 설계 속성을 미터 단위로 수정한다. 길의 점 높이는 설계 중심 기준 높이다. 산 높이는 아래 지형에 더하는 높이다.
4. 지도 색·5m 등고선·급경사 표시를 확인한다. **3D 화면 맞추기**는 레벨 뷰포트를 설계 위치로 이동한다. 색 미리보기는 가벼운 임시 메시이며 충돌 지형이 아니다.
5. **사본 보존 후 적용**을 누르면 실제 Landscape를 만들거나 연결된 Landscape의 전용 편집 레이어를 갱신한다. 완료 후 맵 저장은 사용자가 직접 한다.
6. **설정 저장·불러오기**로 높이·평지·산·길 설계를 다른 맵에서 재사용한다. 저장 위치는 프로젝트 `Saved/CozyTerrainEditor/Presets`다. Git에 자동 보관되는 파일이 아니므로 공유하려면 별도 보관한다.

## 기존 지형에 적용

아웃라이너에서 Landscape를 선택한 뒤 **선택 Landscape 연결**을 누른다. 당시 높이를 기준으로 잡으며 원본 레이어를 삭제하지 않는다. 다른 레이어에서 높이가 바뀌면 기존 기준으로 덮어쓰지 않도록 재적용을 거부한다. 새 설계로 다시 연결해야 한다.

**적용 전 높이 복구**는 마지막 적용 전 전용 레이어 상태를 복원한다. 원본 맵 파일 전체나 시설·소품을 되돌리는 기능은 아니다. 사본은 `Saved/CozyTerrainEditor/Backups`에 있다. 기존 Landscape 위에 새 지형을 중복 생성하는 동작은 거부한다.

## 저장된 예제로 확인

콘텐츠 브라우저에서 `CozyRealm/Maps/EditorExamples/L_TerrainEditorExample`을 연다. **창 → 지형 편집기 → 기존 설계 불러오기**로 저장된 설계를 연결하고 **3D 화면 맞추기**를 누른다. 새 맵에서 시작할 때는 **새 설계**를 쓴다.

예제는 252m 지형에 산·시작 평지·높은 확장 평지와 연결 지면을 둔 형태다. 초록에서 황토색으로 변하는 재질은 높이 확인용이며 최종 잔디나 런타임 도색 재질이 아니다. 예제의 Play는 기본 비행 카메라로 형태를 살피는 용도다. 실제 CozyRealm 게임 모드의 건설·보행·길찾기 통합 검증과 구분한다.

새 지형의 재질은 첫 적용 전에 지정한다. 기존 Landscape의 재질 변경은 그 Landscape의 세부 정보에서 한다. 기존 지면 재질을 레이어 초기화 없이 새 지형에 연결하면 검게 보일 수 있어, 기존 도색 레이어와의 연결은 별도 작업이 필요하다.

## 범위

기본 지형을 만드는 과정은 Landscape 브러시를 직접 만지지 않는 흐름이다. 결과물은 실제 Landscape이므로 이후 기본 언리얼 도구로도 작업할 수 있다. 다만 다른 도구로 높이를 바꾼 뒤에는 새 설계에 다시 연결한다.

첫 버전은 타원형 평지, 완만한 산, 경유점 높이로 연결되는 지면을 다룬다. 길은 지면의 높이와 폭을 만드는 기능이며 길 텍스처·포장 에셋 자동 설치가 아니다. 물·다리·건물·숲 생성, 수직 절벽·동굴, 자유형 평지 윤곽, 설치된 소품 높이 자동 수정은 포함하지 않는다.

기존 지형 연결은 현재 레벨에 로드된 Landscape, 회전 0, 양수 배율, 약 100만 높이점 이하를 우선 대상으로 한다. 설계 액터는 회전 0·배율 1을 유지하고 크기는 설계 수치로 변경한다. 대규모 World Partition 전체 지원은 별도 검증이 필요하다.

실제 빌드·적용·복구 검증 결과는 `docs/지형편집기_구현진행기록_2026-10-27.md`에서 확인한다.
