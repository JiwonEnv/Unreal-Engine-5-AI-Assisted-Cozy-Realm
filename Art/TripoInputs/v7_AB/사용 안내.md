# 모델별 단독 입력 이미지

각 원형은 A(로우폴 형태 참고)와 B(하이폴 스컬핑 참고) 두 장으로 나눈다. 두 이미지는 서로 다른 제작 방향의 입력 후보이며, 정면·측면 멀티뷰 묶음이 아니다.

- 실제 생성용 부품과 시설 완성 모습 참고를 구분한다. 시설 전체를 한 번 생성해서 모듈로 자동 분해하는 용도가 아니다.
- A도 실제 로우폴 메시나 목표 폴리곤 수를 보증하지 않는다. B도 실제 하이폴 메시와 베이크 결과를 보증하지 않는다.
- B는 넓고 연속된 면, 두꺼운 모서리 깎임, 목재의 적은 긴 홈, 돌의 국소적인 찍힘을 적용한 외형 제안이다. 기존 재질 기준은 유지한다.
- 솔잎과 잎 군집은 평면 카드·알파 텍스처 제작 참고다. 줄기·큰 가지와 별도로 제작한다.
- 파일 이름의 항목 번호는 노션의 관리 항목·원형 대응표로 확인한다. 관리 항목 수와 실제 제작할 부품 수는 다르다.
- `_v2`가 있는 경우 제작기록에 선택된 경로를 따른다. 이전 후보도 비교를 위해 보존한다.

이 작업에서는 Tripo 유료 모델 생성을 실행하지 않는다. 생성 후에는 Blender에서 크기, 접합면, 두께, 피벗, UV와 토폴로지를 검토해야 한다.
