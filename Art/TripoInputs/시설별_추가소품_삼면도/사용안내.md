# 시설 추가 소품 — 원본과 삼면도

26종 프랍의 정면·오른쪽 측면·후면을 각각 별도 PNG로 생성한 디자인 추정도다. 실제 동일 3D 모델을 렌더한 정투영도가 아니므로 치수·윤곽·숨은 구조가 완벽히 일치한다고 보증하지 않는다.

- 각 프랍 폴더: 01_정면.png / 02_측면.png / 03_후면.png
- 원본은 인접 폴더 시설별_추가소품_2026-10-31에 보존한다.
- 원본과 새 시점 간 형태 불일치는 Tripo 투입 전에 비교한다. 불일치가 크면 원본 한 장으로 초안을 만든 뒤 Blender에서 구조를 고정하고 실제 렌더 삼면도를 쓰는 편이 안정적이다.
- 원본 사진의 보이지 않던 구조는 AI 추정 제안이다. 기존 v7 확정 기준을 변경하지 않는다.
- 각 기록 JSON에 기준 이미지와 실제 사용 프롬프트를 저장했다. 내장 이미지 생성 도구를 사용했다.
- Tripo 모델 생성 및 크레딧 사용은 실행하지 않았다.
