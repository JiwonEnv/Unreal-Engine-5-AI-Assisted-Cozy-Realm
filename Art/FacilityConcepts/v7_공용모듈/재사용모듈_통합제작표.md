## 11. 시설 재사용 모듈 통합 목록

🙋 사용자 요청: 시설 전체에서 사용하는 재사용 모듈만 모은 이미지와 정보를 별도로 정리한다. 기존 제분소 스컬핑·재질 기준은 유지한다.

🤖 아래 원형 구성·수량·사용처·규격은 착수용 제안이다. 사용자 최종 승인이나 실제 메시 제작 완료가 아니다. 기존 시설 13종 시안에서 반복되는 구조를 합쳤으며, 시설 고유 기능품과 장식은 공용 키트에서 제외한다.

**카운터·선반·작업대의 상판/널 규격**은 W02 목재 단면에서 파생하되, 실제 폭이 달라지면 널 원형을 추가한다. 이 초기 24변형 수량은 넓은 상판·가구 다리 모든 치수까지 확정한 전체 제작량이 아니다. 씨앗함은 현재 B06 중심으로, 여러 시설에 확정 사용된 부품처럼 표현하지 않는다.

### 11-3. 이 통합 목록에서 제외하는 것

- 시설 전용 형태: 신사의 특징 지붕/중심부, 제빵소 오븐, 공방 전용 장비 등은 별도 후보다. 공용 키트에 넣기 위해 기능·실루엣을 바꾸지 않는다.
- 별도 소품: 자루·상자·통·바구니·맷돌·음식·초롱 등 P항목은 기존 소품 원형 재사용으로 연결한다. 건축 모듈 수에 다시 더하지 않는다.
- 식생과 지면: 밀·차 잎은 별도 카드/원형, 토양은 T03. 식생·지면을 목재 테두리와 한 메시/텍스처로 합치지 않는다.
- 변형 정책: 색만 바뀌면 재질 인스턴스/마스크를 먼저 검토한다. 큰 윤곽·길이·접합이 달라지면 메시 변형을 검토한다. 13개 시설마다 공용 키트 전체를 복제 제작하지 않는다.

### 11-4. 먼저 만드는 순서와 Tripo 사용

1. **W01/W02/W04 → A04 → A01/A02/A03:** 제분소 뒤 골조·벽과 판매소 카운터를 단순 블록아웃으로 맞춘다.
2. **R01~R04:** 기준 지붕 경사와 널 겹침을 고정하고, 일반 시설 2종에 같은 부품을 끼워 본다.
3. **W03·S08:** Tripo 초안을 수정해 특징 휜 부재를 스컬프하고 고유 베이크한다. 기존 U14·U13과 같은 원형으로 관리한다.
4. **TS01:** 표준 부재 길이 방향은 U축 반복, 띠 선택은 V축, 끝은 단면 패치. 큰 베벨·휨은 실제 메시. 지붕 색/거칠기 변형부터 시험하고 부족할 때만 TS02를 추가한다.
5. **S01~S07 조립:** 이미 있는 부품을 우선 사용한다. 차양 천 U19와 고유 조형은 필요 부위만 별도 제작한다.
6. **제분소→판매소→나가야:** 스냅·피벗·지붕 끝·문/창 틈·재질 반복을 게임 카메라에서 확인한 뒤 후속 시설로 확장한다.

Tripo에는 시트 전체 대신 필요한 원형의 깨끗한 단독 참고를 사용한다. 직선 반복 부재는 생성 결과를 그대로 쓰지 말고 단면·길이·원점·접합을 규격화한다. 원형별 단독 생성용 컷과 실제 메시/UV 파일은 아직 제작하지 않았다.

**규격 상태:** 1칸 200cm·90도 회전은 기존 기준, 내부 25/50/100cm 스냅과 100/200/400cm 보 길이는 AI 시험 제안이다. 같은 스마트 재질을 쓴다는 것과 게임에서 같은 텍스처를 공유한다는 것은 다르며, 표준 목재는 TS01·특징 원형은 고유 베이크 경로를 우선한다. 커버처로 색을 조정해도 넓은 색 얼룩을 모두 균열/마모로 바꾸지 않는다.

이미지는 내장 이미지 생성 도구로 만든 **조형·분류 참고 시안**이며, 동일한 실제 메시로 접합/분해/베이크를 검증한 결과가 아니다. 10번 시설별 이미지·12분류 공용 키트·8개 조립 묶음을 함께 보고 검토한다.
