# 제분소 지붕·기둥 접합 보완

직전 부분 보완 파일에서 사용자가 표시한 빈 공간과 누락된 받침을 수정했다. 기존 두께감, 큰 실루엣, 140cm 인체, 피벗·공유 메시 기준은 유지했다. 저장된 파일을 기준으로 별도 수정본을 만들었으며, 열려 있는 Blender에서 저장하지 않은 편집은 가져오지 않았다.

## 수정한 부분

- 앞·뒤 박공: 곡선 지붕 하부를 따라가는 실제 두께의 목재 채움 패널을 배치했다. 패널은 기존 가로보·중앙 지주 뒤에 넣어 표면이 겹치지 않게 했다. 제분소 전면의 작업 공간은 열린 상태다.
- 양 측벽 상단: 기존 가로보를 지붕 하부까지 올려 벽 상단과 지붕 사이가 벌어지지 않게 연결했다.
- 뒷벽 중앙: 빠져 있던 34cm 폭 기둥과 받침석을 넣어 상부 회벽·하부 목재 사이의 중앙 틈을 닫았다.
- 작은 지붕: 처마 받침보를 실제 바깥 기둥 중심선 위로 옮기고 기둥 높이를 맞췄다. 벽붙임보, 연결 서까래 3개, 사선 버팀 2개, 양끝 작은 박공 막음을 추가했다. 바깥 기둥 사이의 통로 공간은 유지했다.

신규 원형은 공용 라이브러리의 `07_V07_박공채움_중앙기둥_작은지붕받침` Collection에 있다. 원형 메시를 공유하며 각 배치의 배율은 1이다. 일반 보·패널과 특징 지붕의 원형 구분은 유지한다.

## 확인 범위

다른 시설 12종의 메시·배치가 바뀌지 않았는지 비교했다. 박공 채움 수, 뒷기둥과 받침 높이, 작은 지붕의 기둥과 받침보 접촉, 메시 공유와 배율, 신규 원형의 열린 경계·퇴화 면을 검사했다. 전체, 후면, 낮은 전면, 작은 지붕 접합 확대의 실제 Blender 렌더로 확인했다.

이는 게임용 로우폴의 외형·시각적 접합 보완이다. 건축 구조 계산, 최종 베이크 UV, 재질, 충돌, LOD, 게임 내 검증을 완료한 상태는 아니다. 이전 파일과 수량이 달라졌으므로 기존 원형 개수를 현재 최종 수량으로 그대로 사용하지 않는다.
