# CozyRealm 공용 모듈 · 시설 조립본

플레이어 키 140cm를 기준으로 만든 1차 로우폴 제작본이다. 사용자 확정 사항은 플레이어 키이며, 이 파일의 세부 치수와 시설 배치는 AI가 구현한 검토용 제안이다. 시설 확장 단계와 계절 변형을 확정하지 않는다.

## 파일과 장면

`CozyRealm_공용모듈과시설_140cm_로우폴.blend`를 Blender에서 연다. 상단 장면 선택에서 다음 장면을 전환한다.

1. `01_시설13종_조립검토`: 시설 전체 비교
2. `02_공용모듈_원형모음`: 공용 원형과 규격 파생 부품
3. `03_제분소_140cm비율검토`: 기본 시작 장면
4. `04_신사_140cm비율검토`: 신사 단독 검토
5. `05_피벗_접합기준_확인`: 실제 부품에 표시한 원점과 축

공용 원형은 `00_공용모듈_원형_실제메시공유` Collection에 있다. 기본 24변형, 추가 규격 5개, 특징 부재·기능품 14개, 치수 적용 파생 9개로 총 52개 메시 원형이다. 시설 13종에 배치된 메시 1,674개는 해당 원형 데이터를 공유한다. 시설마다 필요한 원형만 사용한다.

## 제작 규격 제안

| 항목 | 규격 |
|---|---|
| 단위 | 실제 좌표 1m, 화면 cm 표시 |
| 주 배치 격자 | 200cm |
| 보 길이 | 100 / 200 / 400cm |
| 기본 기둥 | 18 × 18 × 220cm |
| 기초 높이 | 30cm |
| 계단 | 높이 15cm, 디딤 깊이 35cm |
| 문 통과 공간 | 폭 100 × 높이 180cm |
| 문짝 | 98 × 178cm |
| 일반 시설 평면 | 400 × 400cm 중심 |
| 나가야·찻집 겸 여관 | 800 × 400cm |
| 차밭 | 600 × 400cm |
| 지붕 경사 | 30도 |

140cm 인체는 비율 비교용이다. 실제 주인공의 머리·몸 비율을 재현한 캐릭터 모델은 아니다. 게임 카메라와 이동·상호작용을 넣은 뒤 문, 처마, 작업대 접근성을 다시 확인해야 한다.

## 피벗 기준

| 부품 | 실제 원점 기준 |
|---|---|
| 기둥·벽·기초 | 밑면 중심 |
| 휜 기둥 | 바닥 접합 기준점 |
| 직선 보 | 시작 접합면 중심, 길이는 로컬 +X |
| 지붕 널 | 시작 접합면의 하단, 로컬 +X가 경사 진행 방향 |
| 문짝 | 경첩 하단; 로컬 Z 회전으로 개폐 |
| 창틀 | 하단 중심 |
| 시설 전체 | 바닥 중심의 조립 원점 Empty |

시설 Collection의 인스턴스 오프셋도 전시용 배치 위치에 맞췄다. Collection을 새로 인스턴스 배치하면 시설의 바닥 중심을 기준으로 배치할 수 있다. 전시 장면에서의 개별 부품 좌표가 시설 전체의 피벗을 뜻하지는 않는다.

## 수정과 재사용

- 같은 부품을 늘릴 때는 연결 복제 `Alt+D`를 사용한다. 편집 모드에서 원형을 수정하면 연결된 모든 부품에 반영된다.
- 시설 전체 이동·회전은 시설 안의 `Bxx_조립원점_200cm그리드` Empty를 사용한다.
- 길이가 다른 보 등은 이미 만들어 둔 규격 부품을 우선 사용한다. 현재 모든 원형과 재사용 배치의 오브젝트 크기 배율은 1이다.
- 특정 부품만 독립적으로 변경하려면 먼저 메시 데이터를 단일 사용자로 분리한다. 단순 복제 여부보다 메시 데이터 공유 상태를 확인한다.
- 기존 장면을 지우지 않고 다른 이름으로 저장하여 수정본을 만든다.

## 재질과 후속 공정

현재 색은 부위 구분용 임시 재질이다. UV는 공용 트림·타일과 특징 부품 개별 UV의 초안이며, 실제 트림 텍스처나 완성 베이크가 포함된 상태는 아니다. 목재는 공용 트림, 벽·석재는 반복 재질, 휜 기둥·맷돌 등의 특징 형태는 고유 베이크를 적용할 후속 기반으로 만들었다.

넓은 면, 두께감 있는 모서리, 읽기 쉬운 실루엣을 기준으로 로우폴을 제작했다. 기존 스컬핑 기준의 국소 패임·균열과 재질의 색 얼룩은 하이폴·커버처·베이크·페인터 작업에서 추가한다. 현재 결과를 최종 아트 품질로 간주하지 않는다.

## 검증 결과와 남은 작업

저장된 Blender 파일을 다시 열어 34개 검사를 통과했다. 피벗 경계, 공유 메시 연결, 크기 배율 1, 140cm 기준 인체, 원형의 열린 경계·퇴화 면, UV 존재를 확인했다. 상세 결과는 `피벗_메시공유_검증.json`, 원형 치수와 시설별 삼각형 수는 `제작_규격과검증.json`에 있다.

닫힌 여러 부품을 조립한 구조이므로 단일 용접 표면이나 내부 겹침 제거를 보장하는 검사는 아니다. 지붕 겹침과 내부 접합을 최종 카메라에서 검토하고, 숨은 면 정리·LOD·충돌·라이트맵·베이크 검증을 진행해야 한다. 현재 일부 건물은 기존 제안인 시설당 5천 삼각형을 초과하므로 최적화 전 결과다. 게임 안의 이동·조작 검증은 아직 수행하지 않았다.
