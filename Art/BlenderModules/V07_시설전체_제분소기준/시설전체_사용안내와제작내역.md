# 시설 전체 로우폴 조립본 · 제분소 기준

사용자가 수정된 제분소의 두께감과 형태감을 긍정적으로 검토한 뒤 다른 시설 제작을 요청했다. 기존 제분소의 메시·배치를 유지하고, 나머지 12개 시설을 V07 시설별 A 이미지의 주요 특징에 맞춰 재구성했다. 최종 외형·세부 치수·방 수·업그레이드 단계의 사용자 확정은 아니다.

## 파일 열기와 수정

`CozyRealm_V07_시설13종_공용모듈_140cm.blend`를 Blender에서 연다. 시작 장면은 판매소 단독 보기다. 상단 장면 선택에서 `B01_신사_단독검토`처럼 B번호가 붙은 장면을 고르면 시설별로 확인할 수 있다. `01_시설13종_조립검토`에서는 기존 제분소와 새 시설 전체를 비교한다.

- 각 시설은 B01~B13 Collection으로 분리했다. 시설 안의 조립 원점 Empty를 옮기면 전체를 이동·회전할 수 있다. Collection 인스턴스 오프셋도 바닥 중심 원점에 맞췄다.
- 공용 라이브러리 `00_공용모듈_원형_실제메시공유` 안의 `00_현재사용_공용원형`에 현재 사용하는 원형을 모았다. `99_이전검토원형_사용안함`은 이전 초안의 미사용 원형이며 숨겨 두었다.
- 현재 원형마다 `사용시설` 속성을 기록했다. 같은 메시를 쓰는 부품을 편집 모드에서 수정하면 여러 시설에 함께 반영된다. 추가 배치는 Alt+D로 연결 복제한다. 독립적인 형태 변경이 필요할 때만 메시를 단일 사용자로 분리한다.
- 배치 오브젝트 배율은 1이다. 길이·폭이 다른 부품은 치수가 적용된 별도 메시 원형으로 관리한다. 원점은 기둥·벽·기초의 밑면 중심, 보의 시작 접합면, 문의 경첩 하단을 사용한다.
- 140cm 비교 인체를 각 시설에 넣었다. 이 인체는 키 비교용이며 실제 주인공의 신체 비례를 재현한 캐릭터는 아니다.

## 제작 상태와 재질 경로

기둥·보·두꺼운 지붕 널·벽·기초는 공용 원형을 재사용한다. 카운터·선반·작업대도 규격 널·다리·가로보를 조립한다. 신사의 금줄, 제빵소의 아치 오븐, 창고의 낮은 앞 지붕, 여관의 단차 지붕 등은 시설별 특징 원형·조립으로 분리했다.

일반 목재·지붕은 TS01 공용 트림 경로, 벽은 T02 반복 재질, 석재는 T01, 소품·천은 AT02 또는 개별 베이크 후보다. 현재 UV는 방향 투영 초안이며 실제 최종 트림 띠에 검수해 맞춘 UV가 아니다. 목재 색·회벽·석재는 구분용 임시 재질이다. 기존에 정한 패임·색 얼룩·커버처 표현은 하이폴과 최종 재질 공정에서 적용한다.

밀과 차 잎은 plane에 공용 알파 아틀라스를 적용했다. 아틀라스 PNG 2장은 이 폴더에 저장하고 Blender 파일에도 내장했다. 외부 파일이 없어도 열 수 있다. 절차적으로 그린 임시 카드 텍스처이므로 최종 식생 아트 품질을 확정한 결과는 아니다. 나뭇잎·솔잎 전체의 최종 제작 완료를 뜻하지 않는다.

## 확인 범위와 미완료

저장된 파일을 다시 열어 시설 13종 존재, 실제 메시 공유, 배율, 원점, 140cm 인체, 기둥 받침 접촉, 닫힌 원형과 의도된 plane, UV 존재, 나가야·여관 문 개수, 뒷벽 중앙·앞 박공 막힘 등을 검사했다. 검사 결과는 `공유_피벗_지지_막음_검증.json`에 있다. 시설별 단독 렌더 12장과 전체 전시 렌더를 확인했다.

기존 A 이미지의 모든 비례·장식·숨은 구조를 정확하게 복원한 결과는 아니다. 공용 모듈로 제작 가능한 형태로 재구성한 로우폴 초안이다. 세부 외형 조정·최종 치수 검토, 고유 UV와 트림 UV 검수, 스컬프·베이크·최종 재질, 충돌·LOD·언리얼 적용과 게임 카메라 검증이 남아 있다. 시설 확장 단계·사계절 변형은 기존 미정 상태를 유지한다. 이번 작업은 로컬 Blender 파일 제작이며 노션의 기존 확정 내용을 변경하지 않았다.
